# Ore Stones Variants Revamped

Мод для **NeoForge и Fabric**. Ветка `1.21.1` — Minecraft 1.21 / 1.21.1; ветка `1.20.1` — NeoForge/Forge 1.20.1. Добавляет варианты всех ванильных руд в **андезите, диорите и граните** — 33 отдельных блока: 8 руд в андезите, диорите, граните и туфе.

## Блоки

`<камень>_<руда>_ore`, где камень: `andesite`, `diorite`, `granite`, `tuff`; руда: `coal`, `copper`, `iron`, `gold`, `redstone`, `lapis`, `diamond`, `emerald`.
Например: `ore_stones_variants_revamped:granite_diamond_ore`.

Дроп, опыт, шёлковое касание и удача — как у ванильных руд. Твёрдость и требуемый инструмент — как у ванильных (угольная/медная/железная/лазуритовая — каменная кирка, остальные — железная).

## Баланс генерации

Руды генерируются **только внутри природных скоплений андезита, диорита и гранита** (Y 0…60, реже выше), **туфа** (глубина, Y -64…-1), поэтому вариантов в мире заметно меньше, чем ванильных руд. Туф и камни не пересекаются по высоте.

Полная таблица (попытки, размер жил, высоты, редкость) лежит в [BALANCE.md](BALANCE.md). Она создаётся скриптом автоматически.

\* Оценка: жила появляется, только если попытка попала в скопление камня (около 2–3% объёма под землёй), реальные цифры зависят от мира.

Идея баланса: дешёвые руды встречаются нормально, ценные (золото, лазурит, алмаз, изумруд) — редкие бонусные находки и не заменяют ванильную добычу.

### Как поменять баланс
Все числа лежат в таблице `ORES` в `tools/generate_resources.py`. Поменяйте значения и запустите:

```
python3 tools/generate_resources.py
```

Скрипт перегенерирует JSON (генерация мира, лут, теги, модели, языки). **Существующие текстуры не перезаписываются.**

## Текстуры

Положите свои PNG 16×16 в `src/main/resources/assets/ore_stones_variants_revamped/textures/block/` с именами блоков, например `andesite_coal_ore.png`. Сейчас там простые временные текстуры, их можно просто заменить файлами с теми же именами.

## Структура ветки 1.21.1

- `common/` — общий Java-код (блоки, камни, вкладка) и **все** ресурсы (текстуры, модели, лут, теги, генерация мира);
- `neoforge/` — вход для NeoForge (Gradle, ModDevGradle);
- `fabric/` — вход для Fabric (Gradle, Loom). Нужен Fabric API.

## Сборка

Готовые jar собирает GitHub Actions и выкладывает в раздел Releases (отдельный файл для NeoForge и для Fabric).

Локально:

```
cd neoforge && ./gradlew build     # JDK 21, jar в neoforge/build/libs
cd fabric   && ./gradlew build     # JDK 25 (как в шаблоне Fabric), jar в fabric/build/libs
```

Ресурсы пересоздаются командой `python3 tools/generate_resources.py` (запускать из корня репозитория).
